Architectural Blueprint

Stateful Multi-Agent Topology

Nexus abandons single-turn prompt chaining in favor of an explicit, cyclic LangGraph StateGraph that supports dynamic task routing, reflection self-correction, and state checkpoints.

🧭

Supervisor Agent

Dynamic orchestrator that analyzes the user's objective, formulates a 4-stage execution plan, tracks step progression, and dynamically routes between specialized agents.

State: plan, current_step, next_agent
🔬

Researcher Agent

Collects empirical data, whitepapers, and live web snippets using search_web. Gathers primary citations and addresses specific critic feedback during revision cycles.

Tools: search_web (DDGS / API)
📈

Data Analyst Agent

Extracts quantitative indicators, percentage changes, financial amounts, and performance benchmarks using extract_metrics to generate verifiable scorecards.

Tools: extract_metrics (Regex & NLP)
⚖️

Critic / Fact-Checker

The reflection engine. Triangulates assertions against collected sources, verifies claims, and computes a 0-100 quality score. Triggers automatic revision cycles if the score is under 80.

Pattern: Reflection & Self-Correction
🛡️

Human-in-the-Loop Gate

Provides an auditable checkpoint via LangGraph's interrupt_before. Allows operators to inspect state, edit prompts, and sign off before final distribution.

Persistence: MemorySaver & SqliteSaver
✍️

Executive Writer Agent

Synthesizes the entire state history into an authoritative executive decision briefing, incorporating an executive summary, KPI scorecard table, and cited sources.

Output: C-Level Markdown Report
Next-Gen LangGraph Features

Time-Travel Replay & Long-Term Memory

Nexus harnesses cutting-edge LangGraph v1.2 capabilities that traditional prompt architectures cannot match: immutable checkpoint rewinding and cross-thread semantic memory stores.

Time-Travel & State History

app.get_state_history(config)

Every node transition is persisted as an immutable checkpoint in SQLite. Operators can inspect the exact historical state at step 2 or step 4, modify input parameters, and fork execution along a new branch without re-running earlier expensive stages.

# Inspect checkpoint timeline via CLI
uv run python -m langgraph_multi_agent_system.cli --time-travel <THREAD_ID>

Cross-Thread Long-Term Memory

langgraph.store.base.BaseStore

Checkpointers manage state within a single thread, but LangGraph's BaseStore provides cross-session recall. Past research discoveries, domain benchmarks, and operator preferences are recalled across completely different threads.

# Search shared memory store via CLI
uv run python -m langgraph_multi_agent_system.cli --memory-search "LangGraph"

Enterprise Observability

End-to-End Tracing via LangSmith

Multi-agent systems cannot be run blindly. Nexus is natively instrumented for LangSmith. Every node invocation, prompt input, token spend, latency delta, and reflection score is recorded in an auditable distributed trace tree.

Sub-Millisecond Span Capture: Track latency bottlenecks across agent handoffs and tool executions.
Granular FinOps Token Accounting: Inspect exact token usage per agent node to prevent cost runaways.
Automated Regression Benchmarks: Custom evaluators continuously score topic coverage and critic rigor.

Developer Setup

Get Started in Under 60 Seconds

Powered by modern uv package manager for instantaneous builds.

1 Clone Repository & Sync Dependencies
git clone https://github.com/phlppgdfry/langgraph-multi-agent-system.git
cd langgraph-multi-agent-system
uv sync
2 Configure LangSmith Credentials
uv run python -m langgraph_multi_agent_system.cli --configure
3 Run Terminal Swarm or Launch Web Dashboard
# Run Rich Interactive CLI
uv run python -m langgraph_multi_agent_system.cli "Analyze Enterprise Agentic FinOps"

# Or Launch Streamlit Web UI
uv run streamlit run src/langgraph_multi_agent_system/app.py
